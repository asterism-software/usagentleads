# Marketing gallery

Five 1600 × 960 PNGs for product directories and launch listings.

| File | Focus |
| --- | --- |
| `01-agent-database-overview.png` | Verified-contact database and nationwide coverage |
| `02-searchable-agent-dashboard.png` | Searchable agent database dashboard |
| `03-instant-csv-delivery.png` | State selection, checkout, and instant CSV delivery |
| `04-rest-api-access.png` | REST API, authentication, rate limits, and quota |
| `05-state-coverage-catalog.png` | State-by-state data catalog |

All images use the product's light UI palette: `#F8F9FB` background, `#0F1623` ink, and `#1D4ED8` accent blue. They have been normalized to 5:3, suitable as high-density master assets and easily downscaled for individual directory requirements.
